## ✨ 核心特性

- 🔒 **强制休息** - 全屏覆盖不可跳过，真正打断连续用眼
- 🧠 **智能感知** - 检测会议/通话等场景，自动推迟休息避免干扰工作
- 🐱 **猫咪陪伴** - 萌猫主题 + 名言警句，让休息更有趣
- 🌍 **多语言支持** - 支持中文和英文界面，随时切换无需重启
- 🎨 **精美界面** - 现代化 UI 设计，适配深色/浅色模式
- 📊 **智能进度条** - 颜色随进度渐深，直观显示使用状态
- ⏱️ **最后10秒提醒** - 休息即将结束时黄色提醒
- 🎯 **零打扰** - 菜单栏常驻，不占 Dock，一键操作

## 🚀 安装

### 下载安装

1. 从 [Releases](https://github.com/bbly-oneday/CatBreak/releases) 页面下载最新的 `CatBreak-vX.X.dmg` 文件
2. 打开 DMG 文件，将 `CatBreak.app` 拖入 Applications 文件夹
3. 首次运行可能需要在「系统偏好设置 → 安全性与隐私」中允许运行

### 系统要求

- macOS 13.0 (Ventura) 及以上
- 支持 Intel + Apple Silicon (Universal Binary)

## 📖 功能说明

### 使用时长计时

状态机逻辑：

```
              用户活跃
  ┌─────────┐  ───────>  ┌────────────┐  达到上限  ┌──────────┐
  │  idle   │            │ monitoring  │ ────────> │ breaking │
  │  待机   │ <───────  │   监控中    │           │  休息中  │
  └─────────┘  离开>10分 └────────────┘           └──────────┘
                      ↑        │                       │
                      │  离开>3分│                       │ 倒计时归零
                      │        ↓                       ↓
                      └── ┌──────────┐          ┌──────────┐
                          │  paused   │          │  idle    │
                          │  已离开    │          │  待机    │
                          └──────────┘          └──────────┘
```

- **idle (待机)**: 等待用户活动，不累计时间
- **monitoring (监控中)**: 每 1 秒滴答，累计使用时长
- **paused (已离开)**: 无输入超过 3 分钟，暂停计时
- **breaking (休息中)**: 全屏覆盖显示，倒计时休息时长

### 空闲检测规则

| 规则 | 阈值 | 行为 |
|------|------|------|
| 进入暂停 | 无鼠标/键盘输入 > 3 分钟 | 计时暂停 |
| 恢复监控 | 离开后 < 10 分钟恢复输入 | 从暂停时的时长继续计时 |
| 重置计时 | 离开 > 10 分钟 | 已用时长清零 |

### 智能会议/通话检测

默认预置 7 款应用：

| 应用 | Bundle ID |
|------|-----------|
| 腾讯会议 | com.tencent.meeting |
| Zoom | us.zoom.xos |
| Microsoft Teams | com.microsoft.teams |
| Chrome | com.google.Chrome |
| FaceTime | com.apple.FaceTime |
| QQ | com.tencent.MacQQ |
| 微信 | com.tencent.xinWeChat |

检测到会议/通话时：
- 自动推迟休息（最多 10 分钟）
- 监测卡片显示「推迟休息」状态
- 超过 10 分钟强制执行休息

### 最后10秒提醒

休息即将结束时（剩余 10 秒）：
- 倒计时数字变为黄色
- 标题变为「马上结束」
- 底部提示「休息时间即将结束，准备继续工作」
- 温和提醒，符合自然配色

## ⚙️ 设置选项

| 设置项 | 说明 | 默认值 |
|--------|------|--------|
| 使用时长限额 | 连续使用电脑的时间限制（1-120分钟） | 60 分钟 |
| 休息时长 | 每次休息的持续时间（10秒-20分钟） | 5 分钟 |
| 语言 | 界面语言（中文/English） | 中文 |
| 自动隐藏延迟 | 窗口自动隐藏时间（5-60秒） | 10 秒 |
| 休息静音 | 休息开始时自动静音 | 关闭 |
| 开机自启 | 登录时自动启动 | 关闭 |

### 进度条交互

- **点击定位**: 点击进度条任意位置，滑块直接跳转
- **拖拽调整**: 拖动滑块精确调整数值
- **刻度标记**: 4个均匀分布的浅色刻度，帮助快速定位
- **颜色渐深**: 数值越大，颜色越深（符合自然配色）

## 🎨 界面特色

### 现代化设计

- **圆角窗口**: 12px 圆角，符合 macOS 设计语言
- **状态徽章**: 圆角胶囊 + 外圈光晕，状态一目了然
- **渐变进度条**: 颜色随进度渐深，视觉反馈直观
- **渐变按钮**: 退出按钮渐变红色，醒目美观
- **窗口定位**: 紧贴菜单栏底部，居中对齐图标

### 深色/浅色模式

- 自动适配系统外观
- 每个组件都有针对性的配色方案
- 深色模式：深色背景 + 橙色强调
- 浅色模式：浅色背景 + 蓝色强调

### 多语言支持

- 支持中文和英文界面
- 切换语言后立即生效，无需重启
- 名言警句自动加载对应语言版本
