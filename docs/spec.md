# CatBreak 需求规格说明书

> 版本: 2.5.0 | 更新日期: 2026-06-07

---

## 1. 产品概述

### 1.1 产品定位

CatBreak 是一款 macOS 菜单栏工具，通过全屏覆盖休息提醒强制用户定时休息，防止长时间持续用眼和久坐。以猫咪为主题，提供沉浸式休息体验。

### 1.2 目标用户

- 长时间使用电脑的办公人群
- 程序员、设计师、文字工作者等需要屏幕前工作的职业
- 关注健康但缺乏自制力的用户

### 1.3 核心价值

- **强制休息**: 全屏覆盖不可跳过，真正打断连续用眼
- **智能感知**: 检测会议/通话等场景，推迟休息避免干扰工作
- **猫咪陪伴**: 萌猫主题 + 名言警句，让休息更有趣
- **现代 UI**: 精美界面设计，适配深色/浅色模式
- **零打扰配置**: 菜单栏常驻，不占 Dock，设置简洁

## 2. 功能需求

### F1. 菜单栏常驻

| 项目 | 说明 |
|------|------|
| **图标** | 猫咪剪影 SF Symbol (`cat.fill`) |
| **左键点击** | 弹出设置面板 (320×550pt 窗口) |
| **右键点击** | 上下文菜单: "打开设置" / "退出" |
| **窗口行为** | 无边框窗口，16px 圆角，居中对齐图标 |
| **Dock 隐藏** | `LSUIElement = YES`, 不显示 Dock 图标, 不出现 Cmd+Tab 切换列表 |

### F2. 使用时长计时

#### F2.1 计时状态机

```
                  用户活跃
    ┌─────────┐  ───────>  ┌────────────┐  达到上限  ┌──────────┐
    │  idle   │            │ monitoring  │ ────────> │ breaking │
    │  待机   │ <───────  │   监控中    │           │  休息中  │
    └─────────┘  离开>10分 └────────────┘           └──────────┘
                        ↑        │                       │
                        │  离开>3分│                       │ 倒计时归零
                        │        ↓                       ↓
                        └── ┌──────────┐          ┌──────────┐
                            │  paused   │          │  idle    │
                            │  已离开    │          │  待机    │
                            └──────────┘          └──────────┘
```

- **idle (待机)**: 等待用户活动, 不累计时间
- **monitoring (监控中)**: 每 1 秒滴答, 累计使用时长
- **paused (已离开)**: 无输入超过 3 分钟, 暂停计时
- **warning (预警)**: 距限额 60 秒时预警状态
- **breaking (休息中)**: 全屏覆盖显示, 倒计时休息时长

#### F2.2 空闲检测

| 规则 | 阈值 | 行为 |
|------|------|------|
| 进入暂停 | 无鼠标/键盘输入 > 3 分钟 | 计时暂停, 状态变为 paused |
| 恢复监控 | 离开后 < 10 分钟恢复输入 | 从暂停时的时长继续计时 |
| 重置计时 | 离开 > 10 分钟 | 已用时长清零, 回到 idle |

输入事件包括: mouseMoved, leftMouseDown, rightMouseDown, keyDown, scrollWheel

#### F2.3 使用时长上限

- 范围: 60 ~ 7200 秒 (1 分钟 ~ 120 分钟)
- 步长: 30 秒
- 默认: 3600 秒 (60 分钟)
- UI 显示: "X分钟" 或 "X分Y秒"

#### F2.4 休息时长

- 范围: 10 ~ 1200 秒 (10 秒 ~ 20 分钟)
- 步长: 10 秒
- 默认: 300 秒 (5 分钟)
- UI 显示: "X分钟" 或 "X分Y秒"

### F3. 全屏休息覆盖

#### F3.1 窗口层级

- 窗口层级: `CGShieldingWindowLevel()` (屏幕保护层级, 高于所有应用)
- 风格: 无边框, 透明背景, 无阴影, 忽略鼠标事件
- 空间行为: 加入所有 Space, fullScreenAuxiliary, stationary (跟随 Mission Control 切换)
- 多显示器: 在每块屏幕创建独立覆盖窗口

#### F3.2 覆盖界面

```
┌──────────────────────────────────────────────────┐
│              [猫咪背景图 / 深色渐变]               │
│                                                  │
│              [45% 黑色半透明遮罩]                  │
│                                                  │
│            🐱 猫咪图标                            │
│                                                  │
│          "名人警句"                              │
│                                                  │
│              该休息啦                            │
│                                                  │
│              04:59                               │
│                                                  │
│        喝杯水 · 站起来 · 看远方 · 想想未来        │
│                                                  │
│  [最后10秒: 黄色倒计时 + "马上结束" 提示]         │
└──────────────────────────────────────────────────┘
```

#### F3.3 最后10秒提醒

- 倒计时数字变为黄色
- 标题变为「马上结束」
- 底部提示变为「休息时间即将结束，准备继续工作」
- 背景卡片增加黄色高亮
- 符合自然配色，温和提醒

### F4. 名言警句

- 数据源: `catbreak.txt` (5200+ 行)
- 解析规则: 跳过标题行、URL 行
- 匹配格式: `数字、警句内容`
- 每次休息随机抽取一条显示
- 兜底文案: "放下键盘，起来活动一下吧！"

### F5. 会议/通话智能检测 (敏感应用)

#### F5.1 敏感应用列表

默认预置 7 款应用:

| 应用 | Bundle ID |
|------|-----------|
| 腾讯会议 | com.tencent.meeting |
| Zoom | us.zoom.xos |
| Microsoft Teams | com.microsoft.teams |
| Chrome | com.google.Chrome |
| FaceTime | com.apple.FaceTime |
| QQ | com.tencent.MacQQ |
| 微信 | com.tencent.xinWeChat |

用户可自定义增删。

#### F5.2 检测策略

检测周期: 监控中每 10 秒, 休息中每 5 秒

**1. 麦克风状态检测:**
- CoreAudio API 查询麦克风是否正在使用
- 检测特定应用进程是否占用麦克风

#### F5.3 推迟机制

| 条件 | 行为 |
|------|------|
| 检测到敏感应用活跃 | 推迟休息 (最多 600 秒 / 10 分钟) |
| 推迟期间 | 监测卡片显示「推迟休息」状态 |
| 推迟超过 10 分钟 | 强制执行休息 |
| 休息中检测到敏感应用 | 提前结束休息 |

### F6. 音量控制

| 场景 | 行为 |
|------|------|
| 休息开始 (muteOnBreak=ON) | AppleScript 保存当前音量 → 静音 |
| 休息结束 (muteOnBreak=ON) | AppleScript 关闭静音 → 恢复原音量 |
| muteOnBreak=OFF | 不进行任何音量操作 |

### F7. 开机自启

- 开关: "开机自启" Toggle
- 实现: `SMAppService.mainApp` API (macOS 13+)
- AppDelegate 中 `applicationDidFinishLaunching` 调用 `SMAppService.mainApp.register()` 完成注册

### F8. 设置面板 UI

#### F8.1 窗口设计

- 尺寸: 320 × 550 pt
- 圆角: 16px
- 背景: 深色/浅色模式自适应
- 位置: 紧贴菜单栏底部，居中对齐图标

#### F8.2 组件

1. **顶部区域**: 品牌标识 (猫咪图标 + CatBreak + 健康休息提醒)
2. **计时区域**: 计时显示 + 进度条
3. **设置区域**: 
   - 使用时长限额滑块
   - 休息时长滑块
   - 暂停休息事件监测卡片
4. **底部操作区域**: 静音、自启动、退出按钮

#### F8.3 滑块特性

- 点击定位: 点击进度条任意位置，滑块直接跳转
- 拖拽调整: 拖动滑块精确调整数值
- 刻度标记: 4个均匀分布的浅色刻度
- 颜色渐深: 数值越大，颜色越深（符合自然配色）

## 4. 非功能需求

### 4.1 性能

- 全局事件监控不显著影响系统性能
- 敏感应用检测异步执行, 不阻塞主线程

### 4.2 兼容性

- macOS 13.0 (Ventura) 及以上
- Intel + Apple Silicon (Universal Binary)
- 多显示器支持

### 4.3 安全性

- App Sandbox: 关闭 (需要监控其他应用窗口)
- Hardened Runtime: 开启
- 无网络请求, 无数据上报

### 4.4 本地化

- UI 语言: 简体中文
- 名言警句: 中文
